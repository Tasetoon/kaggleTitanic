# Kaggle Titanic - Survival Prediction

Классификация пассажиров Титаника по вероятности выживания. 
Три модели: 
- Logistic Regression
- Decision Tree
- Random Forest

Централизованный препроцессинг, разведочный анализ.

## Запуск

```bash
pip install -r requirements.txt
```

Запустить любой ноутбук из `models/` - он сам вызовет `prepare_data()` и сохранит предсказание в `predictions/`.
